# 内化体重污名元分析：统一编码指南（清洁版）

## 1. 使用范围与唯一规则入口

本文件是后续文献筛选、提取、计算、录入和核查的完整编码依据。编码者与 Agent 只需读取本文件即可了解规则，不再需要通过 Excel 的 RULE 表或其他补充文件拼接规则。Excel 用于保存数据。当前使用无论文记录的空白模板；WBIS/WSSQ 保留清洁版表头与三行块，缺失追踪页按第 9 节合并，规则页不保留。既有已编码原文件不覆盖。

使用空白清洁版模板 `clean_codebook_BLANK.xlsx`（本项目存放于 `outputs/01a1bbe7-5c9d-7b11-b04f-b5e0311bb799/`；在其他环境中使用随附的同名模板）。WBIS/WSSQ 各有 28 个有效字段，不要求提供 Covidence 编号。模板只有 WBIS、WSSQ、no_mean_or_sd、not_eligible 四个工作表，不含规则页。空白分隔列不算变量。按表头名称匹配字段，不依赖固定列号；不擅自增删字段。

执行优先级：用户最新直接指令 > 本统一指南。本文件独立提供完整规则，无需另查其他规则文件。维护时直接修改对应正文，不追加更新日志、来源合并记录或历史版本对照。单篇文章的处理结果不要写成通用规则。

证据以原论文及其正式附录、补充材料为准。旧编码、QC 报告和脚本可帮助定位，但不能代替原文证据。遇到量表资格、样本独立性、目标时间点或计算方法的实质性不确定，先保存页码、表号或材料名称，按固定缺失/未解决规则登记，不自行假设；按第 10 节继续处理其余文章，不因个别待确认事项暂停整个批次。

完成标准：每篇文章、每个适用字段均依规则给出确定的处理动作；无法核实的字段以 -999 或规定的未解决状态完成登记，不等待人工后再追加才能交付。确定处理动作不等于对未知事实作出确定判断，也不保证模型零错误。

处理原则：每篇文章必须有可追踪的处理结果，但不要求每个统计量都可获得。字段层面的不确定不得导致丢弃整篇文章的确定信息。能核实的字段照常填写；适用但缺失、信息冲突或现有分类不覆盖的字段使用 -999，并说明原因；不适用的字段及纯结构占位行按规定留空。-999 不能表示“已确认不合格”，也不能代替原文证据。每篇处理完成后应能判断是正常编码、缺统计量、明确排除，还是保留确定信息后仍有待解决项。

## 2. 文献资格与筛选备注

### 2.1 基本纳入要求

- 定量评估 weight bias internalization / internalized weight stigma。
- 实际使用经过验证的自评工具：WBIS、WBIS-M、WBIS-2F、WBIS 短版（如 WBIS-3），或合格的跨文化验证版本；或 WSSQ。
- 文献类型为同行评审期刊文章、博士论文或硕士论文，发表语言为英语。量表可以是非英语翻译版，文献发表语言与量表语言要区分。
- 提取可用的目标量表均值和 SD，或允许计算这些统计量的数据。暂缺统计量的合格量表研究按第 3 节跟踪，不能仅因暂缺均值就判定量表不合格。

### 2.2 不合格或重复报告

以下情况不进入 WBIS、WSSQ 或 no_mean_or_sd：未实际施测合格量表；仅研究感知污名、歧视经历或公众态度等非内化构念；目标变量为他评；纯定性研究；评论、社论或综述；非英语文献；其他不满足基本纳入要求的情况。

不得仅因某个题目摘自 WBIS 就认定为经过验证的合格短版；需核实实际施测版本。只报告子量表也不能冒充全量表统计量。

跨文章发现同一样本、同一波次重复发表时，保留数据最完整的报告，记录其他报告的关联及处理理由，避免重复计入。

### 2.3 人群不作为自动排除理由

临床人群、特殊人群及超重/肥胖人群仍可纳入。以下人群特征保存在现有 mean_calculation 或该篇的处理记录中，不要求访问 Covidence：

- 临床人群：如确诊进食障碍、精神科、住院或门诊，注明 clinical 及细节。
- 特殊人群：如孕妇、运动员、健美/模特、芭蕾舞者、医学学生，注明 special 及细节。儿童、大学生等一般年龄或教育群体本身不算特殊人群。
- 临床/非临床或特殊/非特殊混合样本：注明 mixed 及组成。
- 超重/肥胖目标人群：注明 obese/overweight；同时含非超重、非肥胖者则注明 Mixed。

这些人群备注不等同于 Excel 的 sample_type 分类；sample_type 按第 6 节执行。

## 3. 分表决策：先判断量表，再判断均值和 SD

对每一个“论文 × 独立子样本 × 合格量表 × 目标时间点”分别判断。正式工作表名是 `WBIS`，不是 WBS。

| 条件 | 录入位置 | 具体操作 |
|---|---|---|
| 不满足文献或量表资格 | not_eligible 与排除报告 | 写完整引用和具体理由；不建量表编码块，也不进入缺失统计量表 |
| 合格 WBIS 系列，有可报告或可计算均值，有可用 SD | WBIS | 完成三行编码块 |
| 合格 WSSQ，有可报告或可计算均值，有可用 SD | WSSQ | 完成三行编码块 |
| 合格量表，查找和允许计算后仍没有目标均值 | no_mean_or_sd | missing_statistic 填 mean 或 mean_and_sd；记录引用、目标量表/样本和作者信息；不为该缺均值编码单位建 WBIS/WSSQ 编码块 |
| 合格量表，有均值但缺少可用 SD | 对应量表主表 + no_mean_or_sd | 主表 scale_sd 填 -999，在 mean_calculation 说明缺失；追踪页 missing_statistic 填 sd，同时登记作者信息 |

总体行按上表处理；女性/男性行只在目标量表 mean 和 SD 均可用时编码，缺任一项则仅保留 sex 和最终 paper_id 结构标识、其余留空，不进入缺失追踪。总体均值不可用但至少一个性别组的 mean 和 SD 均可用时，按第 4 节保留三行块及完整性别数据，总体缺失统计填 -999 并登记；总体均值及完整性别数据均不可用时，只登记总体缺失情况，不建主表块。量表资格未确认时按第 3.1 节登记待解决。

同一文章同时使用 WBIS 系列和 WSSQ，应分别判断、分别进入相应表。这不是重复编码。例如 WBIS 有均值而 WSSQ 没有均值时，WBIS 正常编码，WSSQ 的缺失情况进入 no_mean_or_sd，不能因此删除可用的 WBIS 数据。

缺失判断前必须依次检查：正文与主表 → 附录 → 正式补充材料 → 本文允许的计算。仅有干预后得分或变化值、缺少可用基线时，不将其代替基线均值，按 no_mean_or_sd 跟踪并注明原因。向作者索取后仍无法获得的情况保留处理记录，不虚构数值。

### 全文检索与检查范围

- 每篇必须检查整篇正文，包括摘要、引言、方法、结果、讨论、结论、全部表格及表注、图及图注、脚注、附录；学位论文还需定位各子研究及相关章节。目标数据可能出现在任一位置，不能只读摘要、方法或第一张表就结束。
- 分字段检索并结合上下文阅读：量表全名/缩写/版本、mean/M、SD/standard deviation、sample/n、female/women、male/men、age、BMI、baseline、recruitment/data collection 及日期等。一次检索未命中不等于未报告；须检查替代词、断词、表格提取遗漏及相关页面。检索只是定位手段，不能代替核对统计对象。
- 检查论文提及或附带的正式附录和补充材料。若指向的材料不在本地且可合法获取，则检索出版商的正式材料；无法取得时在处理记录明确列出缺少的材料，不能写成“已检查但未报告”。不因等待材料或作者回复而暂停整批。
- 对疑似缺失、冲突、异常数值及提取顺序混乱的表格，直接查看相应原始页面，核实列标题、行标签、括号内统计量、小数点、负号、脚注及样本人数；扫描件可使用可用的 OCR，但最终核对页面，不按乱码猜数。
- 编码前完成全文范围检查；并非要求将全文逐字翻译或摘抄。记录已检查范围及关键证据位置，未能阅读的页面或补充材料必须如实标识。只有完成可访问材料的检查和允许计算后，才可标注 not_reported 或 not_derivable。

已报告但明显不合理的 SD，不猜测替换。核对是否误把 SE 等统计量作为 SD；无法获得可靠 SD 时保留可用均值，按缺失 SD 流程处理并记录异常证据。

工作簿已有 not_eligible 时使用该表；若任务所用旧工作簿没有该表，保留结构并至少在排除报告登记，不擅自增表。

### 3.1 异常情形的固定处理

以下统计量缺失/冲突的占位及追踪动作适用于总体行；女性/男性行优先执行第 4 节完整 mean + SD 条件，缺任一项不编码、不追踪。

| 情形 | 确定的填写动作 |
|---|---|
| 均值与目标样本、量表和 baseline 已确认，但国家、年龄、BMI、样本分类或 n 缺失 | 保留主表数据，缺失适用字段填 -999，说明具体缺失项；不因背景字段缺失将文章转为缺均值 |
| 已确认是条目均分，但 items_n 或作答上下限未能核实 | 保留已确认的均值和同尺度 SD；相应量表字段填 -999 并说明，不假定常见版本；不根据未知条目数换算 |
| 有均值数字，但无法确认是条目均分还是总分尺度 | 不将其作为标准化口径的 scale_mean；进入 no_mean_or_sd，notes 原样保存数值、原文标签和 unclear_metric 原因，待核实后再转换 |
| 仅有总分尺度统计量，items_n 未知，无法转为条目均分 | 进入 no_mean_or_sd；notes 保留原始总分均值、SD、样本信息及条目数待核实原因，不把总分直接录为 scale_mean |
| 正文、表格或补充材料的均值/SD 不一致 | 先核对样本、量表、时间点、尺度和精度，再按第 7.1 节证据顺序选择并记录；优先顺序仍无法解决的冲突才按不可用处理，保留所有冲突值和位置。仅 SD 不可用则填 -999 并跟踪；均值不可用按第 4、9 节保留同块其他行或进入缺失追踪 |
| 量表是否合格、是否实际施测、全文是否符合资格无法确认 | 不冒充明确排除，不把尚未核实等同于无均值；在批次处理记录保存引用、已知量表和统计量、问题及证据，状态为 eligibility_unresolved；继续下一篇 |
| 正文损坏、扫描无法辨认，或关键材料无法取得 | 先尝试可用的文字提取/页面阅读；仍不能核实则保存已知信息，批次处理记录状态为 source_unreadable 或 source_incomplete；不能据此直接判 no_mean_or_sd 或 not_eligible |
| 怀疑与另一报告重复，或样本独立性无法确认 | 保存两篇关联证据及已知统计量，状态为 overlap_unresolved；不直接删除文章，也不把未确认独立的候选样本作为正式独立块重复计入 |
| 合格量表但仅有中位数、四分位数、变化分、回归系数或图示估读值 | 保留这些原始信息于 notes；不默认当作目标均值或擅自换算，按目标均值是否可获得决定 no_mean_or_sd 去向 |
| 原文只有 SE，未给可用 SD，本文未规定相应转换 | 不把 SE 填入 scale_sd；可用均值照常录入，SD = -999 并登记缺失追踪，notes 保留 SE 及其定义 |

异常数值须区分“极端但有效”和“经核查不可用”。仅因数值偏高、偏低、SD 小或不符合预期，不能改为 -999 或删除。已确认违反量表范围、存在数学不可能性或证据冲突且无法消解时，按 invalid_reported_value 或 conflicting_values 处理：相应字段填 -999，保留原值、证据和判断理由。超出反应范围须先核查是否其实为总分尺度，不可直接认定错误。

不可用原因必须区分：not_reported（未报告）、not_derivable（按允许计算仍无法得到）、invalid_reported_value（报告值经核查不可信）、conflicting_values（冲突）、unclear_metric（尺度不明）、out_of_categories（分类不覆盖）。主表写入 mean_calculation，缺失追踪页写入 notes。凡能明确确认的值均保留；只有与目标量表、样本、时间点和尺度的对应关系已核实的均值才能进入正式主表。

资格、可读性或独立性待解决时，使用第 10 节要求的批次处理记录，不增加第五个工作表；记录不是排除结论。正式交付时明确列出这些文章，不能将“全部已处理”表述为“全部已获得完整可分析数据”。

## 4. 编码单位、独立性与固定行结构

### 4.1 固定三行块

每个独立样本、每个合格量表使用一个块，顺序固定：

| 块内行 | sex | 内容 |
|---|---|---|
| 第一行 | 0 | 总样本 |
| 第二行 | 1 | 女性 |
| 第三行 | 2 | 男性 |

块后空一整行，再开始下一块。每个块都保留总体、女性、男性三个行位置，不删除未编码的性别行。

女性/男性行的统一填写条件：只有该性别组的目标量表 mean 和 SD 均已报告或可按本文可靠计算，且对应同一量表、样本、时间点和尺度时，才填写该行。缺 mean、缺 SD 或两者都缺时，仅保留 sex = 1 或 2 及最终 paper_id，其余全部留空；不填写该组人数、年龄、BMI 等部分信息，不用 -999 批量填充该行，不登记该性别组到 no_mean_or_sd，不为补齐该组另行索取数据或生成问题文本。上述条件不取决于原文是否做过性别分层分析。

总体行继续提取或可靠计算总体结果，不能把混合样本中某一个性别组的数据复制成总体。总体 mean 可用但 SD 缺失时，保留总体行，scale_sd = -999，并只登记总体缺失 SD。性别分组 mean 和 SD 完整、但其他适用字段缺失时，可以填写该性别行，其他缺失字段按规则填 -999；不能用总体年龄/BMI 代替未报告的性别特异值。

仅女性或仅男性样本：该组就是总体。总体行照常填写；mean 和 SD 均可用时，在对应性别行复制总体信息，另一性别行仅保留 sex 及最终 paper_id。若 mean 或 SD 缺失，则只按总体缺失规则处理，不再填写或追踪不完整的性别行。这种按要求复制不代表两个独立样本。

每个块必须标明 subsample_label。文章只报告一个合并样本时写 `Overall sample`；独立子样本写具体英文名称。所有实际编码的数据行重复 full_reference、subsample_label 及确实适用于该行的背景信息；未编码性别行仅保留 sex 和最终 paper_id。

若总体均值不可用，但至少一个性别组 mean 和 SD 完整，保留三行块，总体行保留已知信息、缺失统计填 -999 并登记总体缺失；仅填写完整性别组。如果总体均值与完整性别组均不可用，则不建主表块，只登记总体缺失及该样本已知背景信息。

用于可靠计算总体统计量的分组输入即使不满足性别行填写条件，也可以写入 age_calculation 或 mean_calculation 作为计算依据；不因此填写不完整的性别行。

### 4.2 什么时候拆分，什么时候合并

- 不同国家、临床人群、年龄人群、族裔或身份群体等，确为不同独立总体且分别报告统计量时，各建三行块；不能为方便分析自行合并。
- 同一总体的女性和男性属于同一块内的性别行；需要总体值时按第 7 节计算，不再额外把性别行当成独立总体重复建块。
- 同一实验/干预研究的治疗组、控制组若是同一总体的基线划分，本质上属于同一类人群，且需要总体统计，计算并填写 pooled mean 和 pooled SD（公式及信息要求见第 7 节），使用一个总体三行块；不因随机分组或治疗条件不同自动拆成独立总体。缺少计算 SD 的必要信息时不得猜测，按缺失 SD 规则处理。
- 治疗组若实际来自真正独立人群，才按独立子样本分别编码。独立性有疑问时保存证据并标记 unresolved，继续处理其余文章。
- 实验/干预研究只填写干预开始前的 baseline（pre-intervention / pre-treatment）。必须核实测量发生在干预前，不能仅因标为 T1、第一次测量或文中称为 baseline 就认定合格；首次测量若已接受目标干预，不能作为基线。不使用干预中、干预后、随访值或变化值替代。无干预的纵向观察研究使用首次测量；若涉及干预，仍必须满足干预前条件。无法取得或可靠计算干预前总体均值时按第 3 节登记总体缺失；时间先后无法核实时保留原始信息并按基线不可确认处理，不猜测。同一参与者的不同分析分层、不同时间点不得冒充独立样本。
- 同论文、同样本、同量表、同时间点/统计量不得在同一主表重复录入。不同量表分表记录是有效的多量表编码，但不意味着分析时相互独立。
- 同一 WBIS 家族的不同合格版本若都实际施测并分别报告目标统计量，按具体版本各保留一块，在 measure_name、subsample_label 和 mean_calculation 中明确版本及同一样本关联；不能将两个版本的统计量取平均。论文中只在引言提及的版本不另编码。
- sex 仅使用总体、女性、男性三个既定代码，不增加类别或额外性别概念的字段及注释。不能明确对应女性或男性的数据不强行分入这两行；总体统计仍按原文全体样本保留。女性与男性人数之和不覆盖总体时，不用二者合成总体来替换原文全体值。
- 文章中“报告了群体构成比例”不等于报告了群体分别的目标量表统计量。例如仅给出不同族裔的人数/比例而只有总体量表均值时，不能据此为每个族裔虚构可编码均值或机械新建量表块。
- 分别施测、分别报告统计量的不同受访人群可保留各自三行块，例如青少年与其家长；若存在亲子配对或同一家庭关联，须记录这种关系，不能因分块就宣称其统计上完全独立。不要合并不同受访人群来制造一个总体均值。

### 5.1 文献与样本识别

| source_type | 1 = journal_article；2 = dissertation（博士论文）；3 = thesis（硕士论文）；4 = Other。4 是文献类型代码，不自动使其他类型文献符合纳入要求。 |

### 5.2 样本背景

| 变量 | 填写规则 |
|---|---|
| country | 填样本所在国家，不按作者单位推断。美国统一编码为 US（包括 USA、U.S.、United States、United States of America 等原文写法），英国统一编码为 UK（包括 U.K.、United Kingdom 等原文写法），不写这两国的全名。其他国家统一使用常用英文名称，不使用中文或当地语言拼写，例如 Turkey（不写 Türkiye）、Germany（不写 Deutschland）。未报告填 -999。真正合并且无法分开的跨国样本写 Multinational (US, China) 等，其中美国、英国仍使用 US、UK；各国分别提供独立统计量时分别建块。 |

### 5.3 年份

| 变量 | 填写规则 |
|---|---|
| publication_year | 期刊文章使用首次在线发表年份（published online / online first year），不使用正式卷期年份（issue year），也不使用收稿、接受、版权或网页更新年份。查核原文首页或出版商正式记录；无法核实时填 -999 并标明待核实，不自动以卷期年份代替。学位论文没有期刊在线发表日期时，使用论文正式年份。 |
| year_data_collection | 明确报告则用实际收集年份；报告时间区间则取中点并四舍五入到整数年；未报告则用 publication_year − 2，其中期刊文章的 publication_year 必须是首次在线发表年份。若该年份为缺失码 -999，不执行 -999 − 2，收集年份也填 -999。在 mean_calculation 中注明时间区间、推算过程和证据位置，并标明是年份说明。 |
| year_imputed_rule | 1 = reported；2 = midpoint rounded to nearest whole year；3 = publication_year − 2。必须与 year_data_collection 的来源一致。 |

年份区间中点统一使用常规四舍五入（round half up）：小数部分为 .5 时向上取整，不使用银行家舍入（ties to even），也不直接截去小数。例如，数据收集于 2014–2015 年：`(2014 + 2015) / 2 = 2014.5 → 2015`。填写 `year_data_collection = 2015`、`year_imputed_rule = 2`，并在 `mean_calculation` 注明原区间、中点和取整结果。

例如，文章首次在线发表于 2022 年、正式编入 2023 年卷期，则 `publication_year = 2022`；若未报告收集年份，则 `year_data_collection = 2020`、`year_imputed_rule = 3`。full_reference 仍保留所引用正式版本的正确 APA 引用年份；若与 publication_year 不同，在 mean_calculation 注明 online year、issue year 及证据来源，不强行改写引用年份。无法获得可用于推算的发表年份、且未报告收集年份时，year_imputed_rule 填 -999，而非表示已经完成推算的 3。

### 5.4 样本量、年龄与 BMI

| 变量 | 填写规则 |
|---|---|
| sample_n | 使用与该行目标均值实际对应的有效人数；有量表特异有效人数时优先于笼统总人数，不直接用最初招募人数、回归完整案例人数或随访完成数代替。性别行使用对应性别人数。无法核实填 -999；保留已确认的均值和 SD 并注明 n 未知。由百分比推人数仅在分母明确、适用于该样本且按原文精度能唯一确定整数人数时允许，并记录推导；不能任意四舍五入制造人数。 |
| mean_age | 对应行样本的平均年龄；未直接报告但有充分信息时按第 7 节计算。无法找到或计算填 -999。总样本行不能用某一个子组的年龄代替。 |
| age_calculation | 记录年龄推算的实际数值、公式和证据位置，如 (15.00*123 + 21.21*210)/(123+210)。直接报告且无需计算时可留空。 |
| age_group | 按对应样本未提前舍入的平均年龄 a 分类：1 = 11 ≤ a ≤ 15；2 = 15 < a < 18；3 = 18 ≤ a ≤ 25；4 = a > 25。对应 early adolescent、late adolescent、young adult、adult。跨类别样本按平均年龄分类。年龄缺失则填 -999；真实平均年龄低于 11 岁时保留 mean_age，age_group 填 -999，说明 out_of_categories。不得按年龄缺失码 -999 判断为成人。 |
| mean_bmi | 对应行样本的平均 BMI；可按充分信息计算，无法获得或计算填 -999。若有计算，在 mean_calculation 标明 BMI calculation、公式及证据位置。 |

### 5.5 量表版本与计分

| 变量 | 填写规则 |
|---|---|
| measure_name | 填具体合格量表名称，如 WBIS、WBIS-M、WBIS-2F、WBIS_short_form、WSSQ；不要把语言混入名称。各 WBIS 家族版本仍进入 WBIS 表。 |
| translated_flag | 1 = YES，翻译版；2 = NO，英文版。按实际施测语言与版本判断。 |

### 5.6 目标量表统计量与计算说明

## 6. sample_type 判定与临床说明

| 样本情况 | 编码 |
|---|---|
| 非临床、包含非肥胖者（包括肥胖与非肥胖混合） | 1 |
| 全部为肥胖者，非临床 | 2 |
| 全部为肥胖者，且有临床身份依据 | 3；同时填写 clinical_type |
| 有明确临床身份且按本项目归为非肥胖类别 | 4 |

肥胖与非肥胖混合样本归为非肥胖类别；不能因平均 BMI 高或标题提及 obesity 就把全体认定为肥胖。只有全体均为肥胖者才使用 2 或 3。不要把“全部超重或肥胖”直接当作“全部肥胖”。临床身份必须有原文依据，特殊人群身份不自动等于临床。

肥胖与非肥胖混合的样本归为非肥胖类别：非临床填 1，临床填 4；不得仅因 BMI 状态混合而填 -999。只有原文信息不足、无法确定样本 BMI 类别或临床身份时，sample_type 才填 -999，在 mean_calculation 记录已知信息及 classification_unresolved；其他确定字段照常填写，继续下一篇。不按平均 BMI 或治疗组名称猜测分类。

## 7. 允许计算与统计口径

### 7.1 核对统计对象

每个数值录入前确认：目标量表、实际版本、目标样本、目标时间点、全量表/子量表、总分/条目均分、SD/其他离散指标。不能把其他量表、随访结果或分量表的统计量作为目标值。

优先使用原文直接报告且与目标口径一致的总体统计量；缺少所需总体值而分组数据充分时，再按下述方法计算。若直接总体值与分组计算存在实质矛盾，先核实样本量、缺失和计分口径，不自行挑选有利数值。

同一数据多次出现时，按以下顺序判定，不按首次出现、最后出现或出现次数最多来选择：

1. **先确认是不是同一个统计量。** 必须匹配论文/子研究、样本或性别组、有效 n、量表版本、baseline 时间点、全量表或子量表、均值或 SD、总分或条目均分，以及未调整描述统计或模型调整结果。不同对象的数值不构成同一统计量的冲突；本项目需要原始描述统计，不能用调整均值或回归估计替代。
2. **核查精度。** 例如正文 3.5、表格 3.47，若只是正文保留一位小数且二者舍入相容，采用表中较高精度数值，再按本项目精度录入；这不是实质冲突。精度差异无法解释时继续核查，不能自行平均两个数。
3. **正式更正优先。** 已核实的出版商勘误/更正或明确替换目标结果的正式修订优先于被更正原值；不能把网页更新时间当作更正依据。
4. **目标对应关系优先于载体。** 某来源明确对应目标 baseline 及有效样本，另一来源实际对应随访、另一组或另一量表时，选目标来源，不因它是正文或表格而改变。Methods 的实际施测信息用于确定版本，不能被引言的量表概述覆盖。
5. **对象一致且无正式更正时，本项目优先采用列明样本和统计标签的详细描述统计表。** 主表或正式补充表均可，但必须确认是同一目标结果；具有明确行/列标签、n、M/SD 及表注的表格优先于正文简短叙述。若表格与正文分别报 3.47 和 3.74，且二者确为同一目标、表格对应清楚且未发现不合理之处，则按此项目约定录入表格的 3.47，在 mean_calculation 保留正文值、两处位置及“按详细描述统计表优先”的选择理由。该优先顺序用于统一操作，不代表表格天然不会出错。
6. **没有可用详细表格时**，采用明确报告目标结果的 Results 正文；其证据优先于摘要、讨论或结论中的概述。数据只在摘要或讨论等处出现时，只要样本、量表、时间点和尺度可核实且没有冲突，也可使用，记录位置。
7. **同级来源仍冲突或优先来源自身存在无法解释的错误时**，不任意挑选。例如正文两处对同一对象给出不同值且无其他证据，或两张同等明确的描述表互相矛盾、无法辨明主次，则该字段填 -999，reason = conflicting_values，保留两值及位置并按缺失流程处理；其余确定字段照常编码，不等待人工后才能交付。

正式补充材料补充正文未报告的数据时，直接提取其目标统计量；不因为数据位于补充材料就判为无均值。派生计算与直接值不一致时，也必须先核查分组是否覆盖全体、人数及舍入；不能用计算值自动覆盖原文总体值。

### 7.2 总分转条目均分

已确认条目数为 k 时：

```text
M_item = M_total_score / k
SD_item = SD_total_score / k
```

均值和 SD 必须同时换成相同尺度，不能均值除以 k 而 SD 保持总分尺度。条目数不明时不转换，先查证。

若全量表各条目均值齐全、对应相同分析样本和计分口径，可由条目均值计算量表条目均分，记录完整过程；不能仅凭各条目 SD 平均得到量表 SD，也不能无协方差信息从条目 SD 推得量表 SD。

从条目均值重建时，先按原文确认哪些条目反向计分、表中均值是否已经反向处理。仅对尚未反向的条目使用 `M_reversed = response_scale_min + response_scale_max - M_original`，再对目标量表全部 k 个条目均值求和除以 k；不能漏反向或重复反向。已报告的正确全量表均值不因含反向条目而再次反转。记录条目集合、反向依据及实际公式；由条目均值恢复全量表均值后，仍按 SD 是否可用决定是否登记 no_mean_or_sd。

### 7.3 两组总体均值与总体 SD

只在这些组共同构成所需总体、且不存在参与者重复时合并。总体均值需要每组 n 和均值；总体 SD 还必须有每组 SD。缺 SD 不妨碍已具备信息时计算均值，但不能把缺失 SD 当作零或将缺失码 -999 代入合并公式。

```text
N = n1 + n2
M = (n1*M1 + n2*M2) / N
SD = sqrt(((n1-1)*SD1^2 + (n2-1)*SD2^2
           + n1*(M1-M)^2 + n2*(M2-M)^2) / (N-1))
```

SD 公式既包含组内变异，也包含组均值相对总体均值的差异；不能对组 SD 取算术平均。

有女性和男性统计量时，在信息充分且二者构成目标总体的前提下完成总样本行；各性别行仅在其目标 mean 和 SD 均可用时填写。若还有其他参与者未被这两组覆盖，不能声称两组合并值代表全体。

### 7.4 三组及更多组

```text
N = sum(n_i)
M = sum(n_i*M_i) / N
SD = sqrt((sum((n_i-1)*SD_i^2) + sum(n_i*(M_i-M)^2)) / (N-1))
```

三组时对 i = 1, 2, 3 求和即可；更多组按同一公式。实际计算说明需列出全部贡献组、人数、均值、SD 和结果，不能只写“pooled”。真正独立总体不因该公式可用就合并。

年龄合并写入 age_calculation；量表和其他需要说明的计算写入 mean_calculation。先用未舍入数计算，最后再按第 8 节显示。

## 8. 缺失值与数值精度

缺失码统一为数值 `-999`，不再使用 `0` 表示缺失。适用于经查找或允许计算后仍无法获得的适用数据字段；不得把 -999 当作真实观测值、样本量或分类结果参与计算。原有有效代码和真实零保持原意，例如 sex = 0 表示总样本、response_scale_min = 0 可以是合法作答下限。

| 项目 | 缺失处理 |
|---|---|
| mean_age、mean_bmi | 查找或允许计算后仍缺失，填 -999 |
| scale_mean | 总体缺失按第 3、4、9 节处理；总体均值和完整性别组均不可用时不建主表块。性别组缺 mean 或 SD 时仅保留 sex 和最终 paper_id，其余留空、不追踪 |
| scale_sd | 总体行缺失填 -999 并按第 9 节追踪；性别组缺失则不编码该性别行，不用 -999 补齐、不追踪 |
| country | 未报告填 -999，不按作者单位猜测 |
| age_group | mean_age 缺失时填 -999，不按占位值判断年龄组 |
| 其他适用字段 | 确认信息缺失后统一填 -999；有明确的推算规则或有效“不确定”类别时仍按该规则，如缺收集年份用 publication_year − 2，scale_comparable_flag 的不确定类别为 3 |
| 性别行 | 仅目标 mean 和 SD 均可用时编码；否则仅保留 sex 和最终 paper_id，其他全部留空。仅有人数、年龄、BMI 或不完整量表统计量均不填写该性别行；不登记性别缺失 |
| 不适用或可选空格 | 无需填写的 clinical_type、未报告但不要求反推的 scale_total、无需计算的计算说明等保持空白；不是未知适用数据，不填 -999 |
| 联系信息 | 需联系作者却无法获得的姓名/邮箱填 -999，表示缺失，不能将 -999 当作可用邮箱；无需抄送时 CC_Mail 可空 |

数值默认保留两位小数；人数、年份、条目数和分类代码保持其整数含义。缺失码始终显示为 -999，不写成 -999.00。绝对值小于或等于 0.01 的非零数保留首个非零有效数字，不舍入成 0.00，如 0.009、0.002。真实零、有效分类代码 0 与缺失码 -999 必须区分。

## 9. 合并缺失追踪页与排除页的字段

缺失统计量统一登记在 `no_mean_or_sd`，仅跟踪目标量表的总体 mean 或 SD 缺失。记录单位为论文 × 量表 × 独立子样本的总体（sex = 0），同一个对象只登记一次；两者都缺时用 mean_and_sd。女性/男性分组缺 mean 或 SD 时，不进入此页，不因是否做过分层分析改变此规则。

| 字段 | 内容 |
|---|---|
| paper_title | 文章完整题名 |
| APA_reference | APA 完整文献引用 |
| Mail | 需联系作者的邮箱，按原文或可核实来源填写 |
| Author | 对应联系作者姓名 |
| CC_Mail | 需要抄送的作者邮箱；需要抄送但邮箱缺失填 -999，无需抄送时留空 |
| measure_name | 缺失统计量所属的合格量表，与主表名称口径一致 |
| subsample_label | 缺失统计量所属的独立样本标签，与对应块一致 |
| sex | 填 0，仅追踪总体缺失；不登记女性或男性分组缺失 |
| missing_statistic | mean = 缺均值但 SD 可用；sd = 有均值、缺可用 SD；mean_and_sd = 两者都缺。根据核查结果填写，不能把“未查找”直接当作缺失 |
| notes | 查找范围、原文位置、缺失/不可信原因、已有的可用统计值及其尺度、基线或其他必要说明；不可用 SD 的情况同时解释证据 |

总体 mean 缺失时登记总体缺失；若还有 mean/SD 完整的性别组，按第 4 节保留该组及三行块，否则不建主表块。总体 mean 可用、SD 缺失时保留主表总体行，scale_sd = -999，并登记总体缺失 SD。notes 保存与总体缺失相关的已知背景、原始统计量及查找依据。

缺失的女性/男性统计量不登记、不追索，不因只有人数或只报告其中一个统计量而保留部分性别行，也不为此生成问题文本。总体已有价值不依赖补齐性别数据。

合并追踪页不使用主表的固定三行块结构，不需要为每条缺失记录补齐三行。

不能编造联系人或邮箱。登记联系信息不等于已联系作者，也不授权自动发送邮件。

not_eligible 的字段为 full_reference、reason，不保留 Covidence 编号列。引用与排除理由应足够具体，如未施测合格量表、仅使用未经验证的单题、重复样本报告等；同时按任务要求输出排除报告。

## 10. 批次操作与最终质量检查

### 10.1 批次范围与连续执行

- 每个新批次必须先复制 `clean_codebook_BLANK.xlsx`，另存为本批次专用的新工作簿，再开始录入。例如使用 `batch01_codebook.xlsx`、`batch02_codebook.xlsx` 等可区分批次的文件名；目标目录或文件名另有指定时按指定执行。不得直接在空白模板中编码或覆盖模板，不得拿其他批次的已编码工作簿接着填写，也不得重新手工搭建一份可能偏离模板的表。
- 复制后先确认新文件的四个工作表、28 个主表字段和首组三行性别标识与模板一致，且没有论文记录。本批次的逐篇保存、分段复核和最终结果均写入该批次副本。已有同名文件时使用不冲突的新名称，不覆盖其他批次成果；只有恢复同一未完成批次时，才继续其已有副本和检查点，无需重新复制或清空已完成数据。
- 项目总量预计约 450 篇，用户每次在指定 folder 中提供约 150 篇或 150 多篇；本次授权范围是当前指定 folder 的全部目标文章，不自动处理其他目录或之后才加入的文章。
- 开始时清点实际文章清单，区分正文、补充材料和重复文件，记录本批次实际篇数 N。150 是预估数量，不是硬上限；若实际有 153 篇，就处理全部 153 篇。不得按 PDF 文件数将同一文章的补充材料另算为一篇。
- 在既定规则下，从第一篇连续完成到最后一篇，再完成自动核查、必要修正和最终导出。不得完成 50 篇或半批后结束任务、要求用户回复“继续”，也不得把检查点设为人工审批节点。
- 个别文章打不开、材料缺失或判断存在实质歧义时，记录文件名、已查范围、证据位置及待解决问题，继续其余文章。未完成阅读的文章不能直接判为 no_mean_or_sd 或 not_eligible。最终明确区分已完成与待处理，不把未解决条目宣称为已编码完成。
- 逐篇保存提取结果与处理状态；每完成 50 篇论文，必须将当前编码写入并保存到本批次工作簿，同时保存批次处理记录和可恢复的进度检查点，不能只保留在对话、内存或临时提取结果中。随后执行该段自动 double check，修正后再次保存工作簿、处理记录及核查结果，再继续下一段。最后不足 50 篇也执行同样的保存、复核和再次保存流程。检查点至少记录已完成的论文范围、复核状态、本批次工作簿路径及下一篇文件名。若发生工具/运行限制，保留已保存成果及下一篇位置；恢复后从检查点继续，不重复或遗漏已处理文章。以上为执行要求，不表示任何平台都能保证一次运行永不中断。

### 10.2 自动 double check：每约 50 篇一轮，全部完成后再总核查

采用“分段原文复核 + 全批次总核查”，不设置校准阶段，不重新讨论已定规则。

**第一层：分段原文复核。** 每完成约 50 篇文章，自动核查刚完成的这一段；最后不足 50 篇的余段也必须核查。边界按文章数计算，不按编码块或 Excel 行数计算。例如 N = 153 时，分别检查第 1–50、51–100、101–150、151–153 篇。

- 必须重新定位原文或正式补充材料中的证据，不仅重读自己的编码结果。
- 对该段每篇文章核查量表资格与去向、独立样本划分、baseline、28 个字段的适用填写、n、量表版本与条目数、量表均值和 SD 的对应尺度。
- 复算该段全部总分转换及合并统计量，检查年份中点与 .5 向上取整；检查三行块、性别行、缺失占位与缺失追踪页。
- 复查缺均值/缺 SD 和排除结论是否有原文依据，区分“已核查仍缺失”和“材料无法获取或尚未读完”。
- 核查 publication_year 使用首次在线发表年份，而非正式卷期年份；与 full_reference 的 APA 引用年份不同时，检查说明和证据。收集年份需推算时，必须基于首次在线发表年份减 2，不混用卷期年份，也不对缺失码 -999 做减法。
- 发现明确错误时依据原文立即修正，并记录原值、修正值、依据及受影响对象。若属于可能反复出现的执行错误，回查此前已编码的相关条目，不能只修当前段；不因此修改既定规则。
- 保存检查结果后自动开始下一段，不等待用户确认。

**第二层：全批次总核查。** 所有 N 篇均已处理且各段完成复核后，再执行下方最终清单，重点核查覆盖完整性、跨段/跨文章重复样本、分表与缺失追踪一致性、结构、计算及实际导出内容。此轮不要求无差别地再次全文重读所有文章；对异常、冲突、缺失结论和修正涉及条目重新回原文。若发现错误，修正后重新核查受影响范围，避免无依据地重复全批次多轮检查。

内部核查记录另存，不新增清洁版 Excel 规则页或改变 28 个主表字段。记录至少能说明：文章清单、编码状态、分段复核是否完成、修正及证据、未解决项及其处理结果。内部 double check 是当前执行者的自查；任务完成不以人工审批、补填或裁决为前提。未解决值使用规定缺失码或未解决状态交付，不虚构答案，也不宣称自查保证绝对正确。

批次处理记录使用单独的 CSV 或其他可读取结构化文件，至少包含 source_file、full_reference、measure_name、subsample_label、sex、status、affected_fields、known_values、reason、evidence_location、check_completed。status 使用 coded、missing_statistics、not_eligible、eligibility_unresolved、source_unreadable、source_incomplete、overlap_unresolved；主表已有确定数据但个别字段未解决时 status 仍可为 coded，必须在 affected_fields 和 reason 明确列出未解决字段。known_values 保存已核实但暂不能进入主表的信息，不能因尚未裁决而丢失。不要在 MD 中追加各篇处理日志。

### 极少数无法解决问题的文本记录

- 只有在全文范围检查、可获取附录与补充材料检查、原始页面核对、本文允许的计算、证据优先顺序及自动复核均已完成，且现有缺失码、分表和未解决状态仍无法充分处理实质问题时，才创建批次专用 `batchXX_unresolved_issues.txt`，保存在该批次工作簿旁。一个批次集中使用一个文本文件，不为每篇单独建文件。
- 普通未报告数据、可按规则填 -999 的字段、正常 no_mean_or_sd 条目、已有证据顺序可解决的冲突、按本文明确规则登记并隔离的未解决状态，不自动升级到此文本文件。只有现有处理办法仍留下无法可靠执行的实际问题才写入；没有这类问题时不生成空文件。
- 每个问题必须写明：原文文件名、完整引用、对应量表/子样本/sex、涉及字段或操作、具体问题、原文数值或短证据及页码/表号、已尝试的检查与适用规则、这些办法为何仍不足、已经保存的确定信息，以及当前保留/隔离处理。不得只写“需要人工看看”。
- 写入问题不构成人工审批或等待节点，不主动要求用户逐条回复，不阻塞该篇其他确定字段及后续文章。保留可核实信息；无法可靠进入主表的数据保存在处理记录中并隔离，不猜测补齐、不误标为明确排除，也不自动纳入分析。继续完成剩余文章、复核和交付。
- 最终交付仅在实际生成该文件时提供链接，并简要说明尚有多少项不能可靠解决；不得隐瞒这些问题或将其宣称为已确认。是否日后补充证据或人工处理不影响本批次按规则完成交付。

### 10.3 最终检查清单与交付

执行顺序固定为：编码第 1–50 篇 → 自动 double check 并修正该段 → 编码第 51–100 篇 → 自动 double check 并修正该段 → 依此继续至本批次全部文章处理完成（最后不足 50 篇也复核）→ 全批次总核查 → 统一录入论文 ID → 检查 ID 一致性 → 导出并重新读取核对。各步骤自动衔接，不等待用户发出继续指令。论文 ID 不在提取过程中按样本块累加。编号规则：

1. 建立本批次的论文对应表，依据完整题名、作者、引用及可用 DOI 确认同一篇论文；引用格式略有差异不重复分配 ID。不同论文不能仅因作者年份相同而合并；同一论文的多个子研究/样本不是多篇。
2. 先从上到下遍历 WBIS：首次遇到的论文分配 1、2、3……；已分配过的论文沿用原 ID，不因新子样本增加号码。
3. 再从上到下遍历 WSSQ：WBIS 已出现的论文沿用原 ID；尚未出现的论文从当前最大 ID + 1 接续编号，不从 1 重启。
4. 同一论文的全部三行块均使用同一 paper_id，三行位置包括未编码的性别占位行；块间空白行不编号。paper_id 只是论文标识，不能当作新增样本或非空有效数据的判据。
5. 编号从 1 开始、连续不跳号；仅增加新论文才增加号码。核对两张主表的最大 paper_id 等于这两表不同论文的总数。WSSQ 最后一行可能对应已出现的论文，因此不能用最后一行的 ID 代替最大 ID；WSSQ 为空时仍以两表最大值计数。
6. 仅在 no_mean_or_sd、not_eligible 或未解决记录中出现的论文，不为凑齐总篇数强行建立主表块，也不在这两页新增 paper_id 列。主表最大 ID 只表示进入主表的不同论文数；本批次是否全部处理，仍用原文清单与四表、处理记录按论文去重对账，不能只凭最大 ID 判断。
7. 同一批次最终如增删论文或调整去向，重新按上述顺序统一编号并复核，避免断号或跨表不一致。每个新批次从 1 开始，批次之间以文件名区分。


1. 先确认本批次原文目录及从空白模板复制得到的批次专用工作簿，确认未向模板或其他批次文件写入数据，保留模板结构。默认按文件名字母顺序处理；批次另有指示时按指示。
2. 每篇检查正文、表格、附录和补充材料，建立“文章 → 量表 → 样本 → 时间点 → 去向”的对应关系。
3. 完成变量提取与允许计算，保留证据定位；无论可编码、缺均值、缺 SD 或排除，都必须可追踪。
4. 至少再核对一轮：量表、子样本、n、均值、SD、条目数、反应范围、方向及时间点。
5. 检查全部三行块和空行；只有单一性别时检查总体与该性别行一致；不能把这些行重复算成独立研究。
6. 重算所有派生均值及 SD，核查单位一致、人数正确、未提前舍入；不得平均 SD，不得将缺失码 -999 或假定的零当作真实 SD 参与计算。
7. 对 no_mean_or_sd 按 missing_statistic 分别复查均值与 SD 是否可恢复；有均值缺 SD 者核对量表主表记录与说明。
8. 核对排除与跨文章样本重复，确保所有原文有去向；有均值缺 SD 的 no_mean_or_sd 记录是主表记录的附加跟踪，分类计数不能机械相加。
9. 检查每个主表块至少一行有已核实的目标均值；总体行的 -999 仅表示缺失，实际编码的性别行 mean 和 SD 均可用，未编码性别行仅保留 sex 和最终 paper_id；缺失码未参与计算，量表条目数、反应范围、得分尺度与方向相容。
10. 保存到当前任务指定位置并重新读取核对。未指定覆盖原文件时另存，保留原始文件。

### 10.4 分析前的数据有效性检查

- 交付编码数据时，同时根据处理记录给出未解决及不可用项清单；该清单与工作簿以 full_reference、subsample_label、measure_name、sex 对应，不增加主表字段。处理记录不是等待批准的任务队列，不妨碍完成其余编码或使用已确认数据。
- 分析前将适用字段中的 -999 转为分析软件的缺失值；纯结构占位行不作为观测记录。不得对含 -999 的原始列直接计算均值、合并统计量或权重。
- 缺失按当前分析实际需要的字段判断，不能因任意一列出现 -999 就删除整篇。例如 BMI 缺失不自动使已确认的量表均值失效，但该行不能直接用于需要 BMI 的完整案例分析。
- 对需要 n、均值、SD 的常规均值元分析，三者须为已核实、属于同一样本同一时间点且计分尺度一致的数值；n 须满足该分析的计算要求，SD 须满足权重计算要求。任一关键值为 -999、不可用或对应关系未确认，则该行不能直接进入该项分析。不能仅凭数值非空判定可用。
- 资格、目标统计口径或样本重复/独立性仍未确认的候选记录，不自动进入需要这些前提的正式分析，即使存在表面完整的数值。分类字段未解决但资格及统计量已确认时，只影响需要该分类的分析，不自动使全部结果无效。
- 同一总体行及其女性/男性行、同一样本的多个量表版本或关联人群，不自动当作相互独立的数据同时合并。每项分析按其事先确定的目标选取相应行并处理关联；“清除 -999”不等于已解决重复计入或依赖性。
- 因缺失或不可用而未纳入分析的记录保留于原工作簿与处理记录，不从原始编码文件永久删除。后续若获得可靠补充证据，可在副本中修正；补充不是本批次编码交付的必要条件。
